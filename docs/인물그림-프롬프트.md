# 이야기 인물 그림 만들기

`assets/portraits/`의 `jumo.jpg`(주모), `dosa.jpg`(떠돌이 도사), `seonbi.jpg`(선비의 혼)는 임시 그림입니다.
주인공·보스 원화와 같은 화풍으로 그림을 만들어 **같은 파일 이름**으로 올리면 코드 수정 없이 바로 바뀝니다.
(`jang.jpg` 장수는 원화의 '전사' 칸을 잘라 쓴 것입니다.)

## 공통 조건
- 세로 그림, 상반신 위주 (가로:세로 약 4:5, 예: 480×600)
- 얼굴이 위쪽 1/3 안에 오도록
- 동양 판타지 무협 일러스트, 반실사 디지털 페인팅, 섬세한 옷 주름과 장신구, 극적인 조명
- 글자·로고 없이

## 프롬프트 예시

**주모 (jumo.jpg)**
> 동양 판타지 무협 일러스트, 반실사 디지털 페인팅. 조선 시대 고갯마루 주막의 40대 주모. 쪽머리에 금비녀, 연노랑 저고리와 남색 치마, 흰 앞치마. 한 손에 나무 국자. 따뜻하고 넉살 좋은 미소. 뒤로 주막 등불과 따뜻한 주황빛 보케. 상반신, 세로 구도.

**떠돌이 도사 (dosa.jpg)**
> 동양 판타지 무협 일러스트, 반실사 디지털 페인팅. 대숲을 떠도는 늙은 도사. 길게 흘러내린 흰 수염과 흰 눈썹, 상투에 망건, 회청색 도포와 나무 염주. 호리병을 매단 지팡이. 지혜롭고 의뭉스러운 눈빛. 안개 낀 달밤 대숲 배경. 상반신, 세로 구도.

**선비의 혼 (seonbi.jpg)**
> 동양 판타지 무협 일러스트, 반실사 디지털 페인팅. 백 년 동안 떠돈 젊은 선비의 유령. 검은 갓과 흰 도포, 몸이 푸르스름하게 반투명하고 아래로 갈수록 안개처럼 흩어짐. 손에 끝맺지 못한 과거 답안 두루마리. 슬프고 고요한 표정. 보랏빛 어둠 속 떠다니는 한자 글자들. 상반신, 세로 구도.

**장수 (jang.jpg, 바꾸고 싶을 때)**
> 동양 판타지 무협 일러스트, 반실사 디지털 페인팅. 요마성에 갇혀 있다 풀려난 장수. 검붉은 비늘 갑옷과 붉은 망토, 끊어진 쇠사슬이 손목에 남아 있음. 결연한 표정. 불타는 성 배경. 상반신, 세로 구도.

## 올리는 방법
GitHub 저장소 → `assets/portraits` 폴더 → **Add file → Upload files** → 같은 이름의 파일을 올리고 **Commit changes**.
