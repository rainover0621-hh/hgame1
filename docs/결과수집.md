# 학생 결과를 구글 시트로 모으기

학생이 게임을 마치면 결과 화면에서 이름과 반-번호를 적고 **보내기**를 누릅니다.
점수, 정답 수, 정답률, 도착한 스테이지, 완주 여부, 이야기에서 고른 길, 틀린 문제가 선생님의 구글 시트에 한 줄씩 쌓입니다.

> GitHub Pages 주소(`https://rainover0621-hh.github.io/hgame1/`)에서만 동작합니다.
> claude.ai Artifact 링크는 보안 정책상 외부로 데이터를 보낼 수 없습니다.

## 1. 구글 시트와 스크립트 만들기 (한 번만)

1. 구글 드라이브에서 새 **구글 시트**를 만듭니다. 이름 예: `한문 원정기 결과`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 저장소의 `tools/apps-script.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(톱니바퀴): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고, 처음이면 권한 승인을 진행합니다.
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

## 2. 게임에 주소 넣기

1. GitHub 저장소에서 `index.html`을 열고 연필(편집) 버튼을 누릅니다.
2. `const RESULT_URL='';` 줄을 찾아 따옴표 사이에 복사한 주소를 넣습니다.
   ```js
   const RESULT_URL='https://script.google.com/macros/s/여기에-주소/exec';
   ```
3. **Commit changes**를 누릅니다. 1–2분 뒤 GitHub Pages에 반영됩니다.

## 3. 확인

- 게임을 한 판 하고 결과 화면에서 이름을 적어 보내면, 시트 첫 줄에 제목이, 그 아래에 결과가 기록됩니다.
- 보내기를 누르면 학생 화면에는 "보냈어요"가 표시됩니다. 브라우저 보안 때문에 게임에서는 시트에 실제로 들어갔는지까지는 확인할 수 없으니, 처음에는 시트를 직접 확인해 주세요.

## 알아 둘 점

- 학생 개인정보는 이름과 반-번호만 받습니다. 필요하면 이름 대신 별명을 쓰게 안내해도 됩니다.
- 웹 앱 주소를 아는 사람은 누구나 시트에 줄을 추가할 수 있습니다. 수업이 끝나면 Apps Script에서 **배포 관리 → 보관**으로 끌 수 있습니다.
- 같은 학생이 여러 번 보내면 여러 줄이 쌓입니다. 시트의 필터나 정렬로 최고 점수만 볼 수 있습니다.
