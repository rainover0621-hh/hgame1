# 학생 기록 모으기 · 오늘의 순위 · 교사 기록 보기

학생은 게임 첫 화면에서 **학년 · 반 · 번호 · 이름**을 적고 시작합니다. 판이 끝나면 기록이 자동으로 선생님의 구글 시트에 쌓이고,
학생은 **오늘의 순위**에서 오늘 반 전체 순위(학생마다 최고 점수, 이름 가운데 글자는 가림)를 봅니다.
선생님은 **교사용 배포 설정 페이지(teacher.html) 아래쪽 '학생 기록 보기'**에서 날짜 · 학년 · 반별로 기록을 보고 CSV로 저장합니다.

> 아래 설정을 하지 않으면 기록은 학생 기기에만 남고, 오늘의 순위도 그 기기에서 한 기록만 보여 줍니다.
> GitHub Pages 주소(`https://rainover0621-hh.github.io/hgame1/`)에서 동작합니다. claude.ai 미리보기 링크에서는 기록을 보낼 수 없습니다.

## 1. 구글 시트와 스크립트 만들기 (한 번만)

1. 구글 드라이브에서 새 **구글 시트**를 만듭니다. 이름 예: `한문 원정기 기록`
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 모두 지우고 저장소의 `tools/apps-script.gs` 내용을 붙여 넣습니다.
4. 맨 위 `const TEACHER_KEY = '여기에-비밀번호';`의 따옴표 안을 **선생님만 아는 비밀번호**로 바꾸고 저장합니다.
5. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(톱니바퀴): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르고, 처음이면 권한 승인을 진행합니다.
7. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다.

## 2. 게임에 주소 넣기

1. GitHub 저장소에서 `config.js`를 열고 연필(편집) 버튼을 누릅니다.
2. `resultUrl: ''`의 따옴표 사이에 복사한 주소를 넣습니다.
   ```js
   window.HANMUN_CONFIG = {
     resultUrl: 'https://script.google.com/macros/s/여기에-주소/exec'
   };
   ```
3. **Commit changes**를 누릅니다. 1–2분 뒤 반영됩니다.

## 3. 교사 기록 보기

1. `https://rainover0621-hh.github.io/hgame1/teacher.html` 아래쪽 **학생 기록 보기**로 갑니다.
2. 기록 주소는 config.js에 넣었으면 자동으로 채워집니다. **교사 비밀번호**를 넣고 **불러오기**를 누릅니다.
3. 날짜(오늘 / 최근 7일 / 전체), 학년, 반, 이름으로 거르고
   - **학생별 요약**: 최고 점수, 판 수, 완주 횟수, 평균 정답률, 마지막 플레이
   - **모든 판**: 판마다 점수, 정답률, 도착한 곳, 틀린 문제
   를 봅니다. 제목을 누르면 정렬되고, **CSV 저장**으로 엑셀에서 열 수 있습니다.
4. 구글 시트를 직접 열어도 같은 기록이 한 줄씩 있습니다.

## 알아 둘 점

- 시험 모드(`?stage=`, `?boss=`) 기록은 시트에 '시험 모드 O'로 남고, 오늘의 순위에서는 빠집니다.
- 오늘의 순위에는 이름 가운데 글자를 가려서(예: 홍○동) 보냅니다. 전체 이름은 비밀번호가 있어야 볼 수 있습니다.
- 웹 앱 주소를 아는 사람은 누구나 기록을 보낼 수 있습니다. 수업이 끝나면 Apps Script에서 **배포 관리 → 보관**으로 끌 수 있습니다.
- 학생 정보는 학생 기기에 기억되어 다음 판부터 자동으로 채워집니다. 공용 태블릿이면 학생마다 고쳐 적게 안내해 주세요.
