# 한문 원정기

1년 동안 배운 한문(한자, 한자어휘, 한자성어, 고사성어, 문장풀이 등)을 복습하는 달리기 퀴즈 어드벤처 게임입니다.

## 플레이
- `index.html`을 브라우저로 열거나, GitHub Pages 주소로 접속합니다.
- 점프: Space / ↑ / 화면 탭 · 숙이기: ↓ / S · 답 고르기: 1–4 · 붓(힌트): H · 계속: Enter

## 모험가
| 이름 | 유형 | HP | 능력 |
|---|---|---|---|
| 수재 서윤 | 지능형 | 80 | 제한 시간 +8초, 붓 2자루, 점수 ×1.2 |
| 체육부장 강현 | 체력형 | 140 | 받는 피해 30% 감소, 장애물 피해 절반 |
| 육상부 하람 | 민첩형 | 100 | 2단 점프, 회복 ×1.5, 부적 1장 |

## 문제 추가하기
`index.html`의 `BANK` 배열에 한 줄씩 추가합니다.

```js
['분류', 난이도(1 하·2 중·3 상), '질문', '크게 보여 줄 한자', ['정답','오답','오답','오답'], '풀이'],
```

분류: 한자, 한자어휘, 한자성어, 고사성어, 문장풀이, 기타
