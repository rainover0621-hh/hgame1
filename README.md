# 한문 요괴 원정기

1년 동안 배운 한문(한자, 한자어휘, 한자성어, 고사성어, 문장풀이 등)을 복습하는 동양풍 달리기 퀴즈 어드벤처 게임입니다.
글자를 먹는 요괴들을 문제로 물리치며 도화 마을 → 월하 대숲 → 용소 계곡 → 천상 구름궁 네 고개를 넘고, 마지막에 도철의 탄막을 피해야 합니다.

## 플레이
- `index.html`을 브라우저로 열거나, GitHub Pages 주소로 접속합니다.
- 점프: Space / ↑ / 화면 탭 · 숙이기: ↓ / S · 보스 탄막 때 이동: ← / → · 답 고르기: 1–4 · 붓(힌트): H · 계속: Enter

## 모험가
| 이름 | 유형 | HP | 능력 |
|---|---|---|---|
| 서윤 (15세 견습 도사 서생) | 지능형 | 80 | 제한 시간 +8초, 붓 2자루, 점수 ×1.2 |
| 강현 (16세 소년 화랑) | 체력형 | 140 | 받는 피해 30% 감소, 장애물 피해 절반 |
| 하람 (14세 바람 궁수) | 민첩형 | 100 | 2단 점프, 회복 ×1.5, 부적 1장 |

## 문제 추가하기


분류: 한자, 한자어휘, 한자성어, 고사성어, 문장풀이, 기타
